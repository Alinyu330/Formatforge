二、不同设备的使用方法

本工具支持 网页端（PWA）、手机端、电脑桌面客户端 三种使用方式，转换能力一致。

1. PC 网页端（Windows / macOS / Linux）

  1. 用 Chrome 或 Edge 浏览器打开主站 https://formatforge.asia
  2. 点击地址栏右侧的「安装」图标，即可安装为桌面应用
  3. 安装后从桌面/开始菜单直接启动，首次加载完转换引擎后可完全离线使用

2. 手机端（Android / iOS）

Android

  1. 可直接下载安装 Android 客户端（APK）：点击下载 FormatForge-v26.apk 
    国内主链接（加载快）：
https://formatforge.asia/Formatforge/FormatForge-v26.apk

备用链接（GitHub，国内网络可能无法访问）：

    手机直接点击下载；下载后点击安装，需允许「安装未知来源应用」；同签名版本可直接覆盖安装升级

    v21 起客户端支持应用内更新：启动自动检查新版本，确认后自动下载并唤起系统安装器，是否安装由你确认；v26 起「历史版本」页面也在应用内打开（不再跳转浏览器），可离线查看全部版本记录

  2. 也可用 Chrome 打开主站 → 菜单「添加到主屏幕」/「安装应用」，即可像 App 一样使用
  3. 客户端转换引擎已打包在应用内，加载更快；v25 起视频转换速度大幅提升

iOS（iPhone / iPad）

  1. 目前无可直接下载的 IPA 安装包（Windows 环境无法完成 Apple 签名）。推荐用 Safari 打开主站 → 底部「分享」→「添加到主屏幕」，即可像 App 一样使用（PWA）

三、音频转换

1. 音频格式互转

支持的源格式：MP3、FLAC、WAV、AAC、OGG、M4A、WMA、OPUS、APE、WV、AIFF、ALAC、AC3、EAC3、AMR、AU、WEBM 等

可转换的目标格式：MP3、FLAC、WAV、AAC、OGG、M4A、WMA、OPUS、WEBM

操作：选择音频文件 → 选择目标格式 → 可调整比特率/采样率 → 点击「开始转换」

2. 加密音频解密

以下平台加密音乐可直接解密为普通音频：

平台加密格式
QQ 音乐QMC0、QMC3、QMC4、QMC6、QMC8、QMCflac、QMCogg、MGG、MGG1、MGG2、MFLAC、MFLAC0、MFLAC2、BKcmp3、BKcflac、TKM、TKM3、TKM4
网易云音乐NCM
酷狗音乐KGM、KGMA、KWM、VPR、KGG

解密后同样可转换为上述任意目标音频格式。

各加密格式的解密要求

  • QQ 音乐（QMC/MGG/MFLAC/TKM 等）：新版文件需在页面填写 QQ 音乐 UIN 与登录凭证（authst 或 qqmusic_key，或完整 Cookie），程序自动向官方接口获取密钥后解密；旧版文件无需登录即可解密。
  • 网易云音乐（NCM）：直接解密，无需额外配置。
  • 酷狗旧版（KGM/KGMA/KWM/VPR）：直接解密，无需额外配置。
  • 酷狗新版（KGG）：需要酷狗客户端密钥库（KGMusicV3.db）才能解密，详见下文「KGG 解密说明」。

3. KGG 解密说明（重点）

KGG 文件（如 歌曲.kgg.flac）解密需要酷狗客户端密钥库，不同设备操作如下：

  • 电脑端（Electron 客户端）：优先自动读取本机已安装并登录的酷狗客户端密钥库；若未找到，可在酷狗客户端「设置」中导出密钥（复制密钥文本）或直接导入 KGMusicV3.db 文件。
  • 电脑端（网页）：在「酷狗 KGG 密钥库」处导入本机酷狗客户端的 KGMusicV3.db 文件（路径：%APPDATA%\KuGou8\KGMusicV3.db，需已登录酷狗客户端）。
  • 手机端（Root 手机）：程序自动检测到 Root 权限后，可在音频选项中点击「自动读取密钥库」，直接读取手机中已安装并登录的酷狗音乐客户端密钥库，一键解密，无需手动导入。
  • 手机端（未 Root）：程序会提示无法读取本机密钥库。此时需把电脑端的密钥通过文本方式发送到手机再粘贴导入（纯本地解析，不会上传）。注意：不要把数据库文件直接复制到手机使用，请按以下步骤操作：
    1. 电脑端导出：在音频选项「酷狗 KGG 密钥库」中导入 KGMusicV3.db 后，点击 「复制密钥文本」（自动生成密钥文本，或长按手动复制）。
    2. 发送到手机：把复制的密钥文本通过微信 / QQ 等聊天工具发送到手机，或发送到电脑端后复制到剪贴板。
    3. 手机端导入（二选一）：
      • 点击 「从剪贴板读取」，自动读取手机剪贴板中的密钥文本并导入；
      • 或在输入框中长按手动粘贴密钥文本，再点击 「导入文本框内容」。
    4. 导入成功后提示「已加载 N 个密钥」，即可正常解密该账号下载的 KGG 文件。

密钥文本可在聊天软件中直接发送；即使前后附带说明文字或包在 Markdown 代码块里，也能自动识别（v18 起支持 BOM、Markdown 围栏、附加文字与新旧格式）。

密钥库必须来自下载该歌曲的同一酷狗账号，且为最新版本，否则会提示找不到对应密钥。

KGG 手机端解密备用方法

酷狗客户端只有在播放过某首歌后才会把该歌曲的密钥写入 KGMusicV3.db。若手机导入密钥后仍提示找不到密钥，请按以下备用方法操作：

  1. 在 PC 端酷狗客户端登录同一账号，先播放一遍要转换的歌曲（播放几秒即可）；
  2. 等待约 10 秒让密钥写入数据库，再把最新的 KGMusicV3.db（路径：%APPDATA%\KuGou8\KGMusicV3.db）重新导入 PC 网页端并复制密钥文本；
  3. 把新密钥文本发送到手机重新导入，即可解密转换。

嫌麻烦也可以直接在 PC 端解密转换，再把转换好的普通音频文件（MP3 / FLAC 等）传输到手机上使用。

4. 各平台解密 / 转换能力对照

PC 端（网页 + 桌面客户端）可解密的加密格式

平台加密格式所需条件
QQ 音乐（旧版）QMC0 / QMC3 / QMCflac / QMCogg 等无需任何配置，直接解密
QQ 音乐（新版）MGG / MGG1 / MGG2 / MFLAC / MFLAC0 / MFLAC2 / TKM / TKM3 / TKM4 / BKcmp3 / BKcflac需在页面填写 QQ 音乐 UIN + 登录凭证（authst 或 qqmusic_key，或完整 Cookie），通过 PC 浏览器登录 y.qq.com 获取
网易云音乐NCM无需任何配置，直接解密
酷狗（旧版）KGM / KGMA / KWM / VPR无需任何配置，直接解密
酷狗（新版）KGG桌面客户端自动读取本机密钥库；网页端导入 KGMusicV3.db

移动端（手机网页 + Android 客户端）可解密的加密格式

平台加密格式所需条件
QQ 音乐（旧版）QMC0 / QMC3 / QMCflac / QMCogg 等无需任何配置，直接解密
QQ 音乐（新版）MGG / MGG1 / MGG2 / MFLAC / MFLAC0 / MFLAC2 / TKM 等❌ 移动端暂不支持：所需 Cookie 凭证（UIN + authst / qqmusic_key）只能通过 PC 浏览器登录 y.qq.com 获取。请在 PC 端解密转换后再把文件传到手机
网易云音乐NCM无需任何配置，直接解密
酷狗（旧版）KGM / KGMA / KWM / VPR无需任何配置，直接解密
酷狗（新版）KGGRoot 手机可自动读取本机密钥库；未 Root 手机需导入 PC 端复制的密钥文本（见上文 KGG 解密说明）

普通格式（非加密）的音频 / 视频 / 图片 / 表格 / 文档转换，移动端与 PC 端能力一致，均可正常使用。

四、视频转换

支持的源格式：MP4、MKV、WEBM、MOV、AVI、FLV、WMV、MPEG、MPG、M4V、3GP、TS、OGV

可转换的目标格式：MP4、MKV、WEBM、MOV、AVI、FLV、WMV、MPEG、MPG、M4V、3GP、TS、OGV、GIF（GIF 为提取动态图）

操作：选择视频文件 → 选择目标格式 → 可选编码质量（高/中/低）、分辨率（原画/1080p/720p/480p）、帧率 → 点击「开始转换」

五、图片转换

支持的源格式：PNG、JPG、JPEG、WEBP、BMP、ICO、TIFF、TIF、GIF、SVG

可转换的目标格式：PNG、JPEG、WEBP、BMP、ICO、TIFF、PDF（PDF 为把图片合成 PDF）

操作：选择图片文件 → 选择目标格式 → 点击「开始转换」

六、表格转换

支持的源格式：XLSX、XLS、CSV、ODS、HTML

可转换的目标格式：XLSX、XLS、XLSB、XLSM、ODS、FODS、CSV、TXT、HTML

操作：选择表格文件 → 选择目标格式 → 点击「开始转换」

可转换的目标格式：PPTX、TXT、HTML

操作：选择文档文件 → 选择目标格式 → 点击「开始转换」

九、隐私与安全

  • 所有转换均在本地设备完成（浏览器内 WASM 引擎或桌面端原生 FFmpeg），文件不会上传到任何服务器。
  • 仅解密类操作（如 QQ 音乐获取密钥）会请求对应官方接口，且仅传递必要的凭证信息用于解密。
  • 如遇页面空白或异常，请尝试 Ctrl+Shift+R 强制刷新 或清除浏览器站点数据后重试。
